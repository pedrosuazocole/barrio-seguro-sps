# Barrio Seguro SPS

PWA de seguridad comunitaria para San Pedro Sula, Honduras.

## Instalación local
1. Clona o descarga el proyecto.
2. Ejecuta `npm install`.
3. Ejecuta `npm start`.
4. Abre http://localhost:3000

## Despliegue en Railway
1. Sube el proyecto a un repositorio GitHub.
2. Conecta el repositorio a Railway y despliega.
3. (Opcional) Agrega un volumen en Railway y define la variable `DATABASE_PATH=/data/barrio_seguro.db` para persistencia.
4. El dominio público se generará automáticamente.
